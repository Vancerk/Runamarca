# V26.1.1 — entrada correta no tutorial

O tutorial integrado conservava `<base href="/runamarca/">`. Ao abrir `/runamarca/tutorial/`, o navegador buscava o cliente e os estilos da mesa normal; os arquivos exclusivos do guia eram resolvidos fora da pasta do tutorial. Isso também permitia ao cliente normal retomar sua própria sala salva. Separadamente, o acesso por código sempre voltava à mesa, perdendo o destino do tutorial.

A base agora aponta para `/runamarca/tutorial/`. A entrada por código preserva apenas destinos internos reconhecidos do tutorial e o código de uma sala válido. Destinos externos, outras rotas, travessia e arquivos não viram redirecionamentos. O cliente mantém esse destino quando seu acesso expira. Não há mudança de permissões, regras, cartas, formato de checkpoint, chaves do armazenamento do navegador ou tabelas do banco.

## Validação

- Os testes reproduziram a base incorreta e a perda do destino na versão anterior. Uma suposição inicial do teste de que toda instrução pausava o relógio foi corrigida: instruções acionáveis podem continuar rodando; isso não foi tratado como defeito do produto.
- 67/67 testes CPU do tutorial passaram, incluindo seis regressões novas de navegação. Estas executam o formulário real de acesso e a função real de seleção de duelo em VM JavaScript, resolvem e buscam os recursos da página pelo endereço base e verificam seleção/retomada dos três duelos sem substituir a credencial da sala normal.
- 20/20 testes CPU adicionais de acesso, servidor, entrada e versão passaram.
- A regressão de navegação foi acrescentada tanto a `npm test` quanto a `npm run test:tutorial`.

Não foi iniciado navegador nem renderização/GPU local. A VM usa adaptadores de DOM para testar o controlador e o fluxo HTTP; isso não é uma nova validação visual da mesa 3D. O PostgreSQL real e uma conta real no site não foram usados nos testes. A confirmação pública da publicação usa versão/commit, saúde e retorno protegido ao tutorial.

## Publicação e preservação

O reparo está coberto pelo pedido de publicar o jogo completo com os acessos ao tutorial e pela solicitação de corrigir a regressão. Publicação pelo PR protegido e pelo hook existente do mesmo serviço Render, com SHA exato, sem alteração de plano, credenciais ou configurações. Nenhum segredo entra no repositório.

Base publicada anterior: `840ca828e456df7d5bd257afc7669f1281095b34`. O rollback pode usar esse commit no fluxo existente. Os arquivos que determinam a identidade do checkpoint permanecem iguais, preservando os salvamentos do tutorial. As salas normais continuam em memória e podem ser interrompidas por deploy, limitação anterior que este reparo não muda. As prévias e o checkout original não foram alterados.
